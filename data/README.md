# Datos

1. Ingresa a https://www.kaggle.com/datasets/uciml/default-of-credit-card-clients-dataset
2. Haz clic en **Download** (requiere cuenta gratuita de Kaggle).
3. Descomprime y copia `UCI_Credit_Card.csv` en esta carpeta.

Fuente original: Yeh, I. C. y Lien, C. H. (2009). Expert Systems with Applications, 36(2), 2473-2480. Publicado en el UCI Machine Learning Repository.

El CSV no se versiona en el repositorio (ver `.gitignore`).
